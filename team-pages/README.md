**Convention:**

- Copy nội dung từ [`_template.md`](./_template.md)
- Đặt vào branch riêng `feat/<github-user>-intro`
- Mở PR để được merge

> 💡 Các link file phía trên sẽ 404 cho tới khi từng bạn merge PR bài tập 1 của mình — đó chính là mục tiêu của bài tập!
